## 0. 结论摘要（先读）

| 判断 | 说明 |
|------|------|
| **不能整体拷贝合并** | 源仓是 **Python FastAPI 单体 + 前端 SPA**；目标仓是 **Java 17 / Spring Boot 模块化单体 + Next.js 路由分区 + 独立 Python Agent Runtime**。直接拷贝会违反《技术规约》双语言栈边界。 |

## 3. 技术规约冲突明细与修复意见

优先级：**P0** 不修则无法合入主干 · **P1** 合入前必须有方案 · **P2** 可分期。

| ID | 差异点 | 源现状 | 规约/选型要求 | 修复意见 | 优先级 |
|----|--------|--------|---------------|----------|--------|
