## 一、产品概述

### 1.1 产品定位

> **面向中小制造企业，依托大数据和AI技术，提供AI-Native的出海营销服领域的数智化方案。**

| 维度 | 说明 |
|------|------|
| **目标客户** | 有出海需求的中小制造企业（年营收1000万-10亿），覆盖外贸新手到外贸熟手的全spectrum |
| **技术基座** | 大数据（全球贸易大数据、搜索指数、社媒数据）+ AI（大语言模型、多模态模型、智能体） |
| **产品形态** | AI-Native SaaS平台 —— 智能体不是辅助工具，而是各业务环节自主运行的核心驱动力 |
| **业务范围** | 出海营销服全链路：市场分析 → 营销获客 → 销售转化 → 客户服务 |
| **核心价值** | 花一个业务员的成本，获得十个业务员的效率；让外贸新手快速上手，让外贸熟手效率倍增 |

### 1.2 产品特点

**特点一：市场、营销、销售、服务全流程线上化**

- 从市场调研到客户成交再到售后服务，全链路业务活动数字化、线上化
- 消除信息孤岛，实现"获客→培育→转化→履约→复购"的端到端业务贯通
- 全流程数据自动沉淀，形成可持续经营的企业客户数据资产

**特点二：硅基和碳基员工融合**

- 硅基员工（AI智能体）承担数据挖掘、内容生成、自动跟进、异常监测等高重复、高计算密度任务
- 碳基员工（人）聚焦战略判断、关系建立、复杂谈判、创意决策等高价值环节
- 智能任务路由自动分配：简单/重复任务→硅基，复杂/判断任务→碳基，协作任务→碳硅协同

**特点三：智能体在各业务环节自主、智能化运行**

- 五大核心智能体（市场分析、社媒营销、潜客挖掘、销售转化、智能决策）覆盖出海营销服全流程
- 智能体具备自我迭代、自主协作、全年无休的能力，而非被动响应的工具
- 智能体可自主拆解目标、调用工具、执行任务、分析效果、优化策略，形成闭环

### 1.3 五大核心智能体

| 智能体 | 角色定位 | 核心职责 |
|--------|---------|---------|
| **市场分析智能体** | 首席市场分析师 | 搜索趋势分析、热词洞察、贸易数据分析、产品机会识别 |
| **社媒营销智能体** | 社媒营销总监 | 社媒矩阵运营、AI内容生成、访客识别与流量转化 |
| **潜客挖掘智能体** | 营销触达引擎 | 邮件营销EDM、WhatsApp触达、自动开发客户 |
| **销售转化智能体** | 销售运营总监 | 线索管理、客户全生命周期运营、商机跟进、私域自动化 |
| **智能决策智能体** | 首席数据官 | 经营数据分析、问答式数据展示、风险预警、策略优化建议 |

### 2.3 智能体协作架构

五大智能体通过**多智能体协作总线**实现跨域协作：

```
                         ┌─────────────────────┐
                         │   智能决策智能体      │
                         │  （全局协调与决策）    │
                         └─────────┬───────────┘
                                   │ 协调与调度
          ┌────────────────────────┼────────────────────────┐
          │                        │                        │
          ▼                        ▼                        ▼
┌─────────────────┐     ┌─────────────────┐     ┌─────────────────┐
│  市场分析智能体   │────→│  潜客挖掘智能体   │────→│  销售转化智能体   │
│  发现高潜力市场   │ 传递 │  邮件+WA触达     │ 传递 │  转化成交客户     │
│  识别产品机会     │ 目标 │  自动开发客户     │ 线索 │  私域运营管理     │
└─────────────────┘     └─────────────────┘     └─────────────────┘
          │                        │                        │
          │           ┌─────────────────┐                   │
          └──────────→│  社媒营销智能体   │←──────────────────┘
             市场情报   │  社媒内容运营     │     客户案例/素材
                      │  访客识别引流     │
                      └─────────────────┘
```

**典型协作场景：**
1. **市场→潜客→销售**：市场分析智能体发现德国市场机会 → 传递目标客户画像给潜客挖掘智能体 → 潜客挖掘智能体执行邮件/WhatsApp营销 → 产出线索传递给销售转化智能体跟进成交
2. **社媒↔潜客**：社媒营销智能体社媒引流 → 访客识别产出潜客 → 潜客挖掘智能体接手营销触达
3. **决策↔全部**：智能决策智能体监测全局效果 → 发现潜客挖掘智能体在某市场效果差 → 建议市场分析智能体重新评估该市场

## 三、统一工作台

统一工作台是所有碳基员工的**统一数字化工作入口**，也是碳硅协同的操作台。根据不同角色（业务员、运营、主管、老板）自动适配工作界面，并提供智能助手作为人机交互的核心媒介。

### 3.1 工作首页（千人千面）

**公共信息区**

| 功能 | 说明 |
|------|------|
| 行业新闻 | AI智能聚合的全球外贸行业动态、政策法规、汇率变动 |
| 外贸日历 | 全球主要市场节假日、展会日历、重要贸易节点提醒 |

**个性化工作区（按角色适配）**

| 角色 | 核心工作区内容 |
|------|---------------|
| **业务员** | 今日待跟进客户、营销任务执行状态、WhatsApp/邮件未读提醒、本月业绩进度 |
| **运营** | 营销活动效果概览、社媒矩阵运营状态、线索转化漏斗、内容发布日历 |
| **主管** | 团队业绩排行、销售漏斗健康度、客户流失预警、团队任务完成率 |
| **老板** | 全球营收概览、区域市场健康度、ROI分析、战略级预警 |

### 3.2 智能助手

统一工作台内置**智能助手**，是碳基员工与硅基员工（智能体）交互的核心媒介：

| 能力 | 说明 |
|------|------|
| 自然语言问答 | "上个月华东区的外贸销售额是多少？""德国市场的客户增长情况如何？" |
| 任务委派 | "帮我给这批潜客发一轮开发信""把本周的客户跟进情况整理一份报告" |
| 主动建议 | 基于业务上下文主动推荐下一步行动（如："客户A已3天未回复，建议WhatsApp跟进"） |
| 智能体调度 | 根据意图自动路由到对应智能体执行（如："帮我分析下德国市场"→ 市场分析智能体） |
| 多语言支持 | 支持中英文双语交互，方便双语团队协作 |

### 3.3 任务中心

| 功能 | 说明 |
|------|------|
| 统一待办 | 跨系统汇总待处理任务（客户跟进、审批、营销任务审核等），智能排序 |
| 智能分流 | 硅基员工自动处理简单任务，复杂任务提醒碳基员工处理 |
| 任务交接 | 碳硅之间的任务实时交接和上下文传递 |
| 任务追踪 | 任务进度实时跟踪，超时自动预警 |

### 3.4 数据看板

| 功能 | 说明 |
|------|------|
| 经营驾驶舱 | 营收、利润率、客户增长、订单转化等核心KPI可视化 |
| 营销效果看板 | 各渠道获客成本、转化率、ROI对比分析 |
| 销售漏斗 | 线索→商机→成交各阶段转化率实时监控 |
| 智能预警 | 按业务域分类展示预警信息，支持分级推送 |

### 3.5 通知中心

| 功能 | 说明 |
|------|------|
| 询盘提醒 | 新询盘/回复实时提醒，不错过任何商机 |
| 任务通知 | 智能体任务完成、异常、超时等状态通知 |
| 系统消息 | 系统公告、权限变更、数据更新等系统级通知 |
| 预警推送 | 客户流失、营销效果下滑、商机停滞等业务预警分级推送 |

## 四、业务运营中心

业务运营中心是灵犀系统的**业务核心**，覆盖市场、营销、销售、服务四大业务域的全流程线上化运营。由潜客挖掘智能体、社媒营销智能体、销售转化智能体协同驱动，实现从"找到客户"到"服务客户"的端到端贯通。

### 4.1 市场域

市场域聚焦市场运营活动，依托全球市场中心提供的数据底座（搜索指数、热词、贸易大数据），帮助企业在出海前"看清市场"、在运营中"持续监测"。

#### 4.1.1 市场搜索指数

| 功能 | 说明 |
|------|------|
| **搜索趋势分析** | 基于Google Trends等全球搜索指数数据，分析目标品类的搜索热度趋势、季节性波动 |
| **地域热度分布** | 按国家/地区展示搜索热度分布，识别高潜力目标市场 |
| **搜索量估算** | 结合搜索指数和估算模型，输出关键词的月搜索量参考区间 |
| **趋势对比** | 多关键词、多地区的搜索趋势横向对比分析 |

#### 4.1.2 热词分析

| 功能 | 说明 |
|------|------|
| **热搜词排行** | 按行业/品类/地区展示当前热门搜索关键词排行 |
| **上升词发现** | AI识别搜索热度上升最快的新兴关键词，提前布局 |
| **长尾词推荐** | AI推荐高转化潜力的长尾关键词，辅助营销内容选题 |
| **社媒热词** | 聚合TikTok、Facebook、LinkedIn等社媒平台热门标签和话题词 |
| **热词监控** | 自定义关键词监控列表，热度变化自动预警 |

#### 4.1.3 产品机会

| 功能 | 说明 |
|------|------|
| **机会扫描** | AI综合搜索指数、热词趋势、贸易数据，推荐高潜力目标产品/市场组合 |
| **市场容量评估** | 评估目标市场的行业规模、体量、增长潜力 |
| **进入难度评估** | 综合竞争态势、准入门槛评估市场进入难度 |
| **机会报告** | 自动生成产品机会分析报告，含数据图表和策略建议 |

### 4.2 营销域

营销域是获客和品牌建设的核心阵地，由社媒营销智能体和潜客挖掘智能体协同驱动，覆盖社媒运营、内容生成、邮件营销、WhatsApp触达、自动开发客户全链路。

#### 4.2.1 社媒营销

| 功能 | 说明 |
|------|------|
| **社媒账号管理** | 统一管理Facebook、Instagram、LinkedIn、TikTok等社媒账号，授权状态监控 |
| **公众主页授权** | Facebook/LinkedIn公众主页授权管理 |
| **AI内容生成** | 自动生成高质量图文/视频内容，匹配品牌调性，支持多语言 |
| **定时发布** | 按目标市场时区智能排期，自动发帖和运营 |
| **互动管理** | 帖子评论和互动监测，私信回复，评论点赞 |
| **数据汇总分析** | 粉丝数、浏览数、互动率等社媒数据汇总分析 |

#### 4.2.2 邮件营销（EDM）

邮件营销是外贸获客的核心渠道，依托海量高信誉度IP池和真实账号发信，保障行业领先的送达率。

**发送前 —— 营销配置**

| 功能 | 说明 |
|------|------|
| **高送达保障** | 海量高信誉度IP，完善的海外服务器体系，真实账号发信不代发，客户信任度高 |
| **AI写信** | 输入公司名、产品名等，一键生成专业营销开发信，支持多语言、多风格 |
| **AI润色** | 一键修改语法错误，更准确、更专业 |
| **AI改写多版本** | 智能生成多版本邮件正文随机分批发送，平均增加50%送达率 |
| **多维变量** | 一对一专属发信，千人千面，有效提升打开率 |
| **邮件评分** | AI算法智能检测内容、是否命中反垃圾，保障高送达率 |
| **敏感词检测** | 内嵌词库，自动检测敏感词汇和垃圾词汇 |
| **多标题A/B Test** | 多主题测试效果，筛选最优，提高打开率 |
| **海量模板** | 覆盖多场景，支持文本/图文类型，快捷引用 |
| **按时差定时发送** | 无需计算时差，按客户所在国家时区最优时间定时自动发送 |
| **地址过滤** | 智能过滤无效邮箱，筛选近期发送或公共邮箱地址等特殊邮箱 |

**发送后 —— 营销监控与跟进**

| 功能 | 说明 |
|------|------|
| **数据大盘** | 送达、打开、点击、回复、失败、退订等数据实时更新，清晰直观 |
| **详细任务数据** | 每个营销任务的详细执行数据和效果分析 |
| **智能分析报告** | 自动生成营销数据报告，汇总多任务转化情况、高潜用户行为特征，给出优化建议 |
| **状态提醒** | 打开&回复状态实时提醒，不错过任何商机 |

#### 4.2.3 WhatsApp营销

| 功能 | 说明 |
|------|------|
| **号码获取** | WhatsApp号码搜索&过滤、群组号码获取、主动加群获取客户 |
| **账号预热** | 新号自动预热，建立信誉度，降低封号风险 |
| **群发触达** | 多账号群发、精准/安全/分批/定时发送 |
| **多种发送方式** | 立即发送、定时发送、分批发送 |
| **防反垃圾** | 自动检测防反垃圾规则，保障账号安全 |
| **商业号管理** | 商业号群发任务、消息模板、营销统计 |

#### 4.2.4 访客识别与流量转化

## 九、智能体中心

### 9.1 智能体设计理念

智能体（Agent）是硅基员工的产品化形态。在本产品体系中，智能体不是被动调用的AI工具，而是**具备自主目标拆解、工具调用、任务执行、效果分析、策略优化能力的业务主体**。

**核心设计原则：**
- **自主运行**：智能体可自主拆解营销目标，规划执行路径，无需人工逐步指令
- **自我迭代**：基于执行效果数据持续优化策略（如：邮件标题A/B测试自动择优）
- **自主协作**：多智能体之间可自主协商、传递任务、共享知识
- **全年无休**：7×24小时不间断运行，时区无关
